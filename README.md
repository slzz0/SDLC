## Описание проекта
Учебный репозиторий, созданный в рамках выполнения лабораторных работ 
по дисциплине «Жизненный цикл разработки программного обеспечения».

Репозиторий включает:
- материалы лабораторных работ (ветка `lab1` и последующие);
- каркас основного проекта, разработка которого будет вестись в 
  рамках курсового задания.

### Лабораторная работа №1
Разработка программы «Сколько ты проживёшь в интернете» — 
приложение с графическим интерфейсом (MVC), которое по введённым 
пользователем данным (количество часов онлайн в день) рассчитывает:
- сколько лет жизни будет потрачено на интернет;
- количество увиденных мемов;
- количество пролистанной рекламы.

Реализован паттерн MVC (активная модель). Ввод данных выполняется 
через отдельное диалоговое окно, последние введённые значения 
сохраняются и восстанавливаются при повторном открытии.
