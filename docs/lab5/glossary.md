# Глоссарий BuildMate

| Термин | Определение |
|---|---|
| BuildMate | Веб-приложение, в котором покупатель подбирает компоненты ПК под свои задачи и бюджет или проверяет выбранную вручную сборку. |
| Посетитель | Участник, которому доступны общие функции BuildMate. Гость пользуется ими без входа в систему. |
| Пользователь | Посетитель, вошедший в учётную запись. Может сохранять и сравнивать свои конфигурации и включать отслеживание цены. |
| Администратор | Пользователь с правами изменять каталог, загружать прайс-листы и настраивать профили назначения. |
| Комплектующая | Позиция одной из восьми категорий каталога. Артикул (SKU) однозначно определяет позицию при поиске и импорте цен. |
| Конфигурация (сборка) | Набор комплектующих одного ПК. Для ручной проверки можно выбрать только часть категорий. |
| Имеющаяся комплектующая | Деталь, уже принадлежащая покупателю. Подбор учитывает её характеристики во всех вариантах и исключает её цену из суммы покупки. |
| Бюджет | Верхняя граница суммы покупки. Базовая валюта каталога — белорусский рубль (BYN). |
| Профиль назначения | Доли бюджета по категориям и веса CPU и GPU для заданной задачи. Игровой профиль также задаёт допустимое соотношение индексов. |
| Индекс производительности | Для CPU или GPU — оценка модели по шкале 1–100. Для сборки — взвешенная сумма индексов по профилю. У встроенной графики вклад GPU равен нулю. |
| Оценка соответствия | Индекс сборки в процентах от лучшего индекса среди найденных вариантов, с округлением до целого. |
| Совместимость | Выполнение всех применимых условий REQ-FUNC-006. Для неполной сборки результат относится только к выбранным деталям. |
| Применимое правило | Условие, для оценки которого уже известны необходимые характеристики. Например, сравнение сокетов требует выбора и процессора, и платы. |
| Сокет | Разъём процессора. Он должен совпасть с сокетом материнской платы и входить в перечень креплений кулера. |
| Форм-фактор | Стандарт размера платы. Корпус должен поддерживать форм-фактор выбранной платы. |
| M.2 | Разъём платы для установки соответствующего накопителя. Проверка сопоставляет число выбранных M.2-накопителей с числом слотов. |
| TDP | Паспортная тепловая мощность в ваттах. BuildMate использует TDP процессора и видеокарты для оценки мощности блока питания, а TDP процессора также для проверки кулера. |
| Расчётная мощность БП | Минимальная мощность блока питания по правилу BuildMate. Для обычной сборки равна 1,3 × (TDP процессора + TDP видеокарты + 100 Вт). |
| Снимок конфигурации | Состав, характеристики, цены и валюта, зафиксированные при сохранении. По снимку можно восстановить, что именно сравнивал покупатель. |
| Прайс-лист | Таблица CSV, по которой администратор обновляет цену и наличие комплектующих по артикулам. |
| История цены | Начальная цена и последующие изменения цены отдельной позиции с отметками времени. Карточка показывает точки за последние 30 дней. |
| Отслеживание цены | Сравнение текущей стоимости сохранённой сборки с её исходной суммой. При достижении порога BuildMate отправляет владельцу письмо через SMTP. |
