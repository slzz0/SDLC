# ЛР5. Динамическое поведение BuildMate

Посетитель проверяет сборку из каталога. Приложение сопоставляет характеристики выбранных деталей и объясняет каждое нарушение. В модели можно проследить весь путь — от цели посетителя до сообщения с расчётом мощности блока питания.
