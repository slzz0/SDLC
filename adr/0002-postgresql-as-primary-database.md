# PostgreSQL как основная база данных

## Контекст и постановка задачи

BuildMate хранит пользователей, каталог комплектующих, профили назначения и сохранённые конфигурации. SRS прямо требует PostgreSQL для рабочей среды и допускает H2 для автоматизированных тестов (REQ-INT-003). Нужно определить основное хранилище и не допустить зависимости доменной логики от конкретного SQL-драйвера.

## Драйверы решения

- Соответствие REQ-INT-003 и требованиям к целостности данных.
- Поддержка транзакций для сохранения конфигурации и связанных позиций.
- Возможность локального и контейнерного запуска (REQ-INST-001).
- Открытая лицензия и доступность для учебной команды.

## Рассмотренные варианты

- PostgreSQL для разработки и эксплуатации, H2 только для тестов.
- H2 как основная БД.
- Другой реляционный сервер, например MySQL.

## Итог решения

Предлагается использовать PostgreSQL как основную БД, а H2 — только там, где это не искажает поведение PostgreSQL. PostgreSQL задан SRS, поэтому смена основной БД потребует изменения требования и отдельного согласования.

### Последствия

- Хорошо: выполняется ограничение SRS и доступны транзакции и реляционные ограничения.
- Плохо: нужно управлять миграциями и тестировать совместимость с PostgreSQL, а не полагаться только на H2.
- Нейтрально: схема данных должна учитывать снимки цен и наименований для сохранённых конфигураций (REQ-REL-002).

### Подтверждение

Проверить запуск приложения с PostgreSQL в Docker Compose и прогнать миграции на чистой базе. Интеграционные сценарии хранения проверить именно на PostgreSQL.

## Плюсы и минусы вариантов

### PostgreSQL

- Хорошо, потому что прямо соответствует SRS и подходит для транзакционных данных.
- Плохо, потому что требует отдельного сервиса при локальном запуске и настройке CI.

### H2 как основная БД

- Хорошо, потому что легко запускать в памяти.
- Плохо, потому что противоречит REQ-INT-003 и может скрыть различия SQL-диалектов.

### Другой SQL-сервер

- Хорошо, потому что может подойти существующей инфраструктуре.
- Плохо, потому что нарушает явно заданное требование и не даёт пользы для масштаба проекта.

## Дополнительная информация

Связанные требования: REQ-INT-003, REQ-REL-001, REQ-REL-002, REQ-INST-001. Проектные элементы: SDD, раздел 3.3 и 3.5.
